5. Badge Format Observation

Elena uses a special format for badge_sistemi that includes HTML styling:

Safe|<b>Sistema 230V SAFEzone:</b><br>412 + E045S o E145S + SAFEcoder

This format combines:

  • Badge name (before the pipe): Safe, Green, etc.
  • HTML description (after the pipe): Styled text with <b> and <br> tags

This format is valid but doesn't directly match simple badge names in IDML. The validation correctly identifies the badge (Safe/Green) but flags the formatted description as "not found" in simple comparison.
